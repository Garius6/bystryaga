# Демо: сервис "Заметки"

Небольшой REST-сервис на быстряге, показывающий вместе все три User
Story: типизированные обработчики с авто-валидацией/JSON (US1),
`/openapi.json`+`/docs` (US2), логирующий middleware + `при_старте`-хук
(US3).

Хранилище ненастоящее (каждая созданная заметка не сохраняется между
запросами — panos не допускает top-level мутируемое состояние) — файл
показывает форму API, не продакшн-хранилище.

## Запуск

Из корня репозитория:

```
panos demo/заметки_сервис.pns
```

Слушает `:8090`.

## Проверка

```
curl -X POST http://127.0.0.1:8090/заметки -d '{"заголовок": "Купить хлеб", "текст": "и молоко"}'
# 201 {"ид":...,"заголовок":"Купить хлеб","текст":"и молоко"}

curl -X POST http://127.0.0.1:8090/заметки -d '{"заголовок": ""}'
# 422 {"ошибка":"заголовок не может быть пустым"}

curl http://127.0.0.1:8090/заметки
# 200 [{"ид":1,...}, {"ид":2,...}]

curl http://127.0.0.1:8090/openapi.json
curl http://127.0.0.1:8090/docs
```

Каждый запрос логируется в stdout сервера через middleware
(`МЕТОД путь`).
