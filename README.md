# быстряга

Типизированный HTTP-фреймворк для [panos](https://github.com/Garius6/panos)
— надстройка над `std/сеть/http.pns` (не замена и не параллельная
реализация роутинга/сервера). Тот же сдвиг, что дал FastAPI поверх
Starlette: декларативная регистрация маршрутов с типизированным телом
запроса/ответа, авто-разбор/валидация/сериализация JSON, бесплатная
OpenAPI/Swagger-документация из уже объявленных типов.

panos не поддерживает декораторы и runtime-рефлексию сигнатур —
регистрация через generic-методы (`апи.отправить_пост(путь,
нулевое_тело, обработчик)`), не `@app.post("/x")`.

## Установка

```
pan add https://github.com/Garius6/быстряга
```

## Быстрый старт

См. [quickstart.md](quickstart.md) — полный TODO-API пример, прогнанный
целиком (реальный `curl` против запущенного `панос`-скрипта).

```
импорт быстряга

реализация быстряга.ТелоJSON для ЗадачаВвод
	функ заполнить_из_json(это: ЗадачаВвод, значение: json.Значение) -> Опция(Ошибка)
		...
	конец
конец

реализация быстряга.Валидируемое для ЗадачаВвод
	функ проверить(это: ЗадачаВвод) -> Опция(Строка)
		...
	конец
конец

реализация быстряга.ОтветJSON для Задача
	функ в_json(это: Задача) -> json.Значение
		...
	конец
конец

функ старт() -> Пусто
	пер апи = быстряга.приложение()
	апи.отправить_пост("/задачи", нулевое_тело, обработчик)
	апи.получить("/задачи", обработчик)
	апи.маршрутизатор.получить("/openapi.json", быстряга.документация(апи))
	апи.запустить(8080.0, 1.0)
конец
```

## Возможности

- **Типизированные маршруты** — `.получить`/`.удалить`/`.отправить_пост`/
  `.отправить_put`/`.отправить_patch`, JSON-тело разбирается и
  валидируется автоматически (`ТелоJSON`/`Валидируемое`), ответ
  сериализуется автоматически (`ОтветJSON`), явный HTTP-статус через
  `Отклик(О)`.
- **OpenAPI/Swagger** — `быстряга.документация(апи)`/`.swagger_ui()`
  строят `/openapi.json`/`/docs` из уже зарегистрированных маршрутов
  (без детальной JSON Schema тела/ответа — путь+метод есть всегда).
- **Middleware + lifecycle-хуки** — `.middleware(м)` оборачивает весь
  конвейер (включая сопоставление маршрута) в порядке регистрации,
  с коротким замыканием; `.при_старте`/`.при_остановке`.
